# Audit artifacts

Committed reports live here (e.g. `coverage.md`, `scraping-compliance.md`),
generated by `tessera preflight`. `eval/` holds the hand-kept step pairings for
`tessera eval`; `pilot-2026-10.md` is the written record of the first live
pilot (fundsache, kita-platz). Raw crawl snapshots go to `reports/raw/`
and are git-ignored.
